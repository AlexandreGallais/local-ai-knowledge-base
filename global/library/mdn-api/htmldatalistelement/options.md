# HTMLDataListElement: options property

The **`options`** read-only property of the `HTMLDataListElement` interface returns an `HTMLCollection` of `HTMLOptionElement` elements contained in a `<datalist>`. The descendant `<option>` elements provide predefined options for the `` control associated with the `<datalist>`.

## Value

An `HTMLCollection` of `HTMLOptionElement` elements.
