# CSSScale: y property

The **`y`** property of the `CSSScale` interface gets and sets the ordinate or y-axis of the translating vector.

## Value

A `CSSNumericValue`. Can be set to a number, which is wrapped in a `CSSUnitValue` of `unit: "number"`.
