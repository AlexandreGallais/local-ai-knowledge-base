# CSSSkewY

The **`CSSSkewY`** interface of the CSS Typed Object Model API represents the `skewY()` value of the individual `transform` property in CSS.

## Constructor

- `CSSSkewY()`
    Creates a new `CSSSkewY` object.

## Instance properties

_Also inherits properties from its parent interface, `CSSTransformComponent`._

- `ay`
    Returns or sets the y-axis value.

## Instance methods

_Also inherits methods from its parent interface, `CSSTransformComponent`._
