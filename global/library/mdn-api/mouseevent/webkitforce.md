# MouseEvent: webkitForce property

The **`webkitForce`** read-only property of the `MouseEvent` interface is a proprietary, WebKit-specific numeric property whose value represents the amount of pressure that is being applied on the touchpad or touchscreen.

## Specifications

_Not part of any specification._ Apple has a description at the Mac Developer Library.
