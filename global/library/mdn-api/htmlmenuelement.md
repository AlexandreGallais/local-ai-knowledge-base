# HTMLMenuElement

The **`HTMLMenuElement`** interface provides additional properties (beyond those inherited from the `HTMLElement` interface) for manipulating a `<menu>` element.
`<menu>` is a semantic alternative to the `` element.

## Instance properties

_Inherits properties from its parent, `HTMLElement`, and its ancestors._

- `HTMLMenuElement.compact` (deprecated)
    A boolean determining if the menu displays compactly.

## Instance methods

_Inherits methods from its parent, `HTMLElement`, and its ancestors._

_`HTMLMenuElement` doesn't implement specific methods._
