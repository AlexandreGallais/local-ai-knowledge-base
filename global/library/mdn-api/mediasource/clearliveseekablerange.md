# MediaSource: clearLiveSeekableRange() method

The **`clearLiveSeekableRange()`** method of the
`MediaSource` interface clears a seekable range previously set with a call
to `setLiveSeekableRange()`.

## Syntax

```js
clearLiveSeekableRange()
```

### Parameters

None.

### Return value

None (`undefined`).
