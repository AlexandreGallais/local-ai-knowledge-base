# NotRestoredReasons: url property

The **`url`** read-only property of the
`NotRestoredReasons` interface returns a string representing the URL of the navigated page or ``.

## Value

A string.

If the document is in a cross-origin ``, `url` will return `null`.

See Monitoring bfcache blocking reasons for examples.
