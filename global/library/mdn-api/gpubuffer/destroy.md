# GPUBuffer: destroy() method

The **`destroy()`** method of the
`GPUBuffer` interface destroys the `GPUBuffer`.

## Syntax

```js
destroy()
```

### Parameters

None.

### Return value

None (`undefined`).

## Examples

```js
const output = device.createBuffer({
  size: 1000,
  usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_SRC,
});

// some time later

output.destroy();
```
