# HTMLDataElement

The **`HTMLDataElement`** interface provides special properties (beyond the regular `HTMLElement` interface it also has available to it by inheritance) for manipulating `<data>` elements.

## Instance properties

_Inherits properties from its parent, `HTMLElement`._

- `HTMLDataElement.value`
    A string reflecting the `value` HTML attribute, containing a machine-readable form of the element's value.

## Instance methods

_No specific method; inherits methods from its parent, `HTMLElement`._

## See also

- The HTML element implementing this interface: `<data>`.
