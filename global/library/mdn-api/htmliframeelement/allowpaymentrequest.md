# HTMLIFrameElement: allowPaymentRequest property

The **`allowPaymentRequest`** property of the
`HTMLIFrameElement` interface returns a boolean value indicating
whether the Payment Request API may be invoked on a cross-origin iframe.

## Value

A boolean value.
