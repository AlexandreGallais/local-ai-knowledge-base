# SharedStorageRunOperation: run() method

The **`run()`** method of the
`SharedStorageRunOperation` interface defines the structure to which the `run()` method defined inside a Run output gate operation should conform.

## Syntax

```js
run(data)
```

### Parameters

- `data`
    An object representing any data required for executing the operation.

### Return value

A `Promise` that fulfills with `undefined`.
