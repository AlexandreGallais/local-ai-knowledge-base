# VideoFrame: timestamp property

The **`timestamp`** property of the `VideoFrame` interface returns an integer indicating the timestamp of the video in microseconds.

## Value

An integer.

## Examples

The following example prints the `timestamp` to the console.

```js
console.log(VideoFrame.timestamp);
```
