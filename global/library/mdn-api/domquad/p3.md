# DOMQuad: p3 property

The **`DOMQuad`** interface's **`p3`** property holds the `DOMPoint` object that represents one of the four corners of the `DOMQuad`. When created from `DOMQuad.fromRect()`, it is the point (x + width, y + height).

## Value

The `DOMPoint` object includes the following double-precision floating-point values:

- `DOMPoint.x`: The horizontal coordinate.
- `DOMPoint.y`: The vertical coordinate.
- `DOMPoint.z`: The depth coordinate.
- `DOMPoint.w`: The perspective value. The default value is 1.0.

Each of these values is **unrestricted**, meaning that it is allowed to be infinite or invalid (that is, its value may be `NaN` or `±Infinity`).
