# MediaKeyStatusMap: has() method

The **`has()`** method of the
`MediaKeyStatusMap` interface returns a `Boolean`, asserting
whether a value has been associated with the given key.

## Syntax

```js
has(key)
```

### Parameters

- `key`
    The key whose value you want returned

### Return value

A `Boolean`.
