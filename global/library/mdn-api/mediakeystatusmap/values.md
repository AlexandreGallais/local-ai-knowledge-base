# MediaKeyStatusMap: values() method

The **`values()`** method of the
`MediaKeyStatusMap` interface returns a new Iterator object, containing
values for each element in the status map, in insertion order.

## Syntax

```js
values()
```

### Parameters

None.

### Return value

A new iterator.
