# ScrollTimeline: source property

The **`source`** read-only property of the
`ScrollTimeline` interface returns a reference to the scrollable element (_scroller_) whose scroll position is driving the progress of the timeline and therefore the animation.

## Value

An `Element`.

See the main `ScrollTimeline` page for an example.
