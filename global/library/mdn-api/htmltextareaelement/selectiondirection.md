# HTMLTextAreaElement: selectionDirection property

The **`selectionDirection`** property of the `HTMLTextAreaElement` interface is a string that indicates the direction in which the user is selecting the text.

For general information about this property, see `HTMLInputElement.selectionDirection`.

## Value

A string: `"forward"`, `"backward"`, or `"none"`.
