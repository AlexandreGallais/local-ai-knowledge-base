# WorkerNavigator: appCodeName property

The **`appCodeName`** read-only property of the `WorkerNavigator` interface is always `"Mozilla"`, in any browser. This property is kept only for compatibility purposes.

> **Note:**
> Do not rely on this property to return a real
> product name. All browsers return `"Mozilla"` as the value of this property.

## Value

The string `"Mozilla"`.
