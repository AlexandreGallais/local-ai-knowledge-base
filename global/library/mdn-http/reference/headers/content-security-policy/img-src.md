# Content-Security-Policy: img-src directive

The HTTP `Content-Security-Policy` **`img-src`** directive specifies valid sources of images and favicons.

       | CSP version
       | 1

       | Directive type
       | Fetch directive

       |  fallback
       |
        Yes. If this directive is absent, the user agent will look for the
        `default-src` directive.

## Syntax

```http
Content-Security-Policy: img-src 'none';
Content-Security-Policy: img-src <source-expression-list>;
```

This directive may have one of the following values:

- `'none'`
    No resources of this type may be loaded. The single quotes are mandatory.
- ``
    A space-separated list of _source expression_ values. Resources of this type may be loaded if they match any of the given source expressions. For this directive, the following source expression values are applicable:
    - `<host-source>`
    - `<scheme-source>`
    - `'self'`

## Examples

### Violation cases

Given this CSP header:

```http
Content-Security-Policy: img-src https://example.com/
```

The following `` is blocked and won't load:

```html
<img src="https://not-example.com/foo.jpg" alt="example picture" />
```
