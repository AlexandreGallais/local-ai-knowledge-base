# `rel="noreferrer"` HTML attribute value

The **`noreferrer`** keyword for the `rel` attribute of the ``, `<area>`, and `<form>` elements instructs the browser, when fetching the target resource, to omit the `Referer` header and otherwise leak no referrer information — and additionally to behave as if the `noopener` keyword were also specified.
