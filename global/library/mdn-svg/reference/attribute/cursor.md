# cursor

The `cursor` attribute specifies the mouse cursor displayed when the mouse pointer is over an element.

> **Note:**
> As a presentation attribute, `cursor` also has a CSS property counterpart: `cursor`. When both are specified, the CSS property takes priority.

## Elements

The following elements can use the `cursor` attribute:

- Container elements
- Graphics elements
