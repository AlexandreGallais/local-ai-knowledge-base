# `::-webkit-slider-thumb` CSS pseudo-element

The **`::-webkit-slider-thumb`** CSS pseudo-element represents the "thumb" that the user can move within the "groove" of an `` of `type="range"` to alter its numerical value.

## Syntax

```css
::-webkit-slider-thumb {
  /* ... */
}
```

## Specifications

Not part of any standard.
