# Pseudo-classes (part 2 of 2)

## Alphabetical index

Pseudo-classes defined by a set of CSS specifications include the following:

A

- `:active`
- `:active-view-transition`
- `:active-view-transition-type()`
- `:any-link`
- `:autofill`

B

- `:blank` (input) (experimental)
- `:blank` (page)
- `:buffering`

C

- `:checked`
- `:current` (experimental)

D

- `:default`
- `:defined`
- `:dir()`
- `:disabled`

E

- `:empty`
- `:enabled`

F

- `:first`
- `:first-child`
- `:first-of-type`
- `:focus`
- `:focus-visible`
- `:focus-within`
- `:fullscreen`
- `:future`

H

- `:has-slotted`
- `:has()`
- `:heading`
- `:heading()`
- `:host`
- `:host()`

- `:interest-source`
- `:interest-target`
- `:invalid`
- `:is()`

L

- `:lang()`
- `:last-child`
- `:last-of-type`
