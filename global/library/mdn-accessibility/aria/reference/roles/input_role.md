# ARIA: input role

The `input` abstract role is a generic type of widget that allows user input.

> **Warning:**
> The `input` role is an abstract role. It is included here for completeness of documentation. It is not to be used by web authors.

## Description

The `input` role is an abstract role. It must not be used by web authors. It is the superclass for input widgets that provide for user input, including `checkbox`, `radio`, and `textbox`. For all three, consider using the `` element of type `checkbox`, `radio` and `text`, respectively.
