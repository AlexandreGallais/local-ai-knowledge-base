## Names to keep

When several English names mean the same thing, write the first one.

| Same thing | Name to keep |
| --- | --- |
| attached pump, shaft-driven pump, engine-driven pump | Attached pump |
| isolation valve, stop valve, shut-off valve | Isolation valve |
| transfer switch, transfer switching equipment, automatic bus transfer | Transfer switch [S40] [S44] |
| withdrawable, draw-out | Withdrawable [S47] [S51] |
| switch-disconnector, load-break switch, isolator | Switch-disconnector [S46] |
| earth fault monitor, insulation monitoring device, ground fault detector | Earth fault monitor [S61] |
| gear wheel, gear, cogwheel, cog | Gear wheel [S16] |
| fluid coupling, hydraulic coupling, fluid drive | Fluid coupling [S11] |
| dog clutch, positive clutch, jaw clutch | Dog clutch [S10] |
| reducer, increaser, expander | Reducer |
| inverter (DC to AC converter); uninterruptible power supply (backup supply) | two devices: never mix them |
