# angular-testing index

One line per document. Open only the documents your task needs.

- [Run Angular tests with ng test](run-tests.md): Read the test builder in angular.json, then run ng test once, on one file or test, with Vitest or Karma.
- [Angular tests, old to new](test-old-to-new.md): Replace Jasmine, Karma, fakeAsync, detectChanges and the old testing modules in Angular 17 to 22 tests.
- [Test a component, a service and a route with the zoneless TestBed](testbed-v22.md): The zoneless TestBed of Angular 22 for components, signals, HTTP and routes, with wrong and right examples.
- [Test a TypeScript class that drives SVG](svg-class-tests.md): Test the classes that animate synoptic symbols, with a simulated DOM, a fake clock, and a real browser for geometry.
