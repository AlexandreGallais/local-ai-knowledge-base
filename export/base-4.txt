# Evaluation of the base

Does the AI succeed more often with the base than without it, with no more tokens? This folder holds
the task set, the protocol and the record format. Run it on the workstation, with the real model.

## How to run the evaluation

1. Prepare two copies of the same trial project: one with the base at its root (`node import.ts
   --project`), one without.
2. For each task of the set, start a new session of the coding assistant in non-interactive mode,
   with the task text as the prompt, in each copy. Repeat each task the number of runs of the table.
3. After each run, judge success with the check of the task, and note the tokens that the assistant
   reports for the run.
4. Write one line per run in `results.csv` (format below), then run
   `node scripts/evaluation-summary.ts evaluation/results.csv`.

A small team can only see large gaps: about 40 runs per condition are needed to see a gap of
30 points. Start with tasks on APIs and versions that a model does not know well: that is where the
base changes the result.

## Task set

Fake data only. Replace or add real tasks of the team, written without real data.

| Id | Task (prompt) | Success check | Runs |
| --- | --- | --- | --- |
| T1 | Add a standalone Angular component that shows a list of valves with their position, in Angular 22. | `npm run check` and `npm run build` at zero errors; no `standalone: true`, no `*ngFor` | 4 |
| T2 | Add an input `tagName` and an output `selected` to the component, with signals. | Same checks; `input()` and `output()` used | 4 |
| T3 | Add a minimal API endpoint `GET /valves/{tagName}` with typed results and validation, in .NET 10. | `dotnet build` at zero errors; `TypedResults` used | 4 |
| T4 | Log the opening of a valve with a structured message. | `dotnet build` at zero errors (CA2254 on) | 4 |
| T5 | Write the Dockerfile of the API project. | `hadolint` clean; two stages; `USER $APP_UID`; port 8080 | 4 |
| T6 | Write the Deployment and Service of the API, for Kubernetes 1.37. | `kubeconform -strict` and `kube-linter` clean | 4 |
| T7 | Give the properties of a motorized butterfly valve, with their units. | Names from the catalog; each number ends with a suffix of the closed list | 4 |
| T8 | Code the synoptic symbol of a pressure transmitter with its alarm limits. | Lint at zero errors; `highLimitBar` and `lowLimitBar`; badge flashes only when unacknowledged | 4 |
| T9 | Explain this C excerpt (an interrupt handler that clears a register bit). | No invented name; "called by the hardware" said | 4 |
| T10 | Read the requirements in `specs.docx` and list them. | The file is read through `.extract/` only, never raw | 4 |

## Record format

`results.csv`, one line per run:

```text
task,condition,run,success,tokens
T1,with,1,1,18250
T1,without,1,0,22410
```

- `condition`: `with` or `without`.
- `success`: `1` or `0`, from the check of the task.
- `tokens`: the total that the assistant reports for the run.

`results.csv` holds measures of the workstation: keep it out of the public repository unless the team
decides otherwise.

using System.Globalization;
using Microsoft.Extensions.Logging;

namespace Sample.Domain;

/// <summary>Opens and closes valves, and reads their state from a file.</summary>
public sealed class ValveService(IValveRepository repository, ILogger<ValveService> logger)
{
  /// <summary>Opens a valve and saves it.</summary>
  public async Task OpenAsync(Valve valve, CancellationToken cancellationToken)
  {
    ArgumentNullException.ThrowIfNull(valve);
    valve.IsOpen = true;
    await repository.SaveAsync(valve, cancellationToken);
    logger.LogInformation("Valve {Tag} opened", valve.Tag);
  }

  /// <summary>Reads a pressure in bar from a text, whatever the culture of the machine.</summary>
  public static double ParsePressure(string text)
  {
    return double.Parse(text, CultureInfo.InvariantCulture);
  }

  /// <summary>Whether a tag names a valve.</summary>
  public static bool IsValveTag(string tag)
  {
    return tag.StartsWith("V-", StringComparison.Ordinal);
  }
}

import { HttpClient } from '@angular/common/http';
import { inject, Injectable } from '@angular/core';
import { firstValueFrom } from 'rxjs';

import { isValve, type Valve } from './valve';

@Injectable({ providedIn: 'root' })
export class ValveApi {
  private readonly http = inject(HttpClient);

  public async loadValves(): Promise<Valve[]> {
    const body = await firstValueFrom(this.http.get<unknown>('/api/valves'));

    if (!Array.isArray(body) || !body.every(isValve)) {
      throw new Error('The valve list has a wrong shape.');
    }

    return body;
  }

  public async isOpen(id: string): Promise<boolean> {
    const valves = await this.loadValves();

    return valves.some((valve) => valve.id === id && valve.state === 'open');
  }

  public async close(id: string): Promise<void> {
    await firstValueFrom(this.http.post<unknown>(`/api/valves/${id}/close`, {}));
  }
}

  successRate: number;
  tokens: number;
}

export interface EvaluationSummary {
  with: ConditionSummary;
  without: ConditionSummary;
  passes: boolean;
}

function summarize(rows: string[][]): ConditionSummary {
  const successes = rows.filter((row) => row[3] === '1').length;

  return {
    runs: rows.length,
    successes,
    successRate: rows.length === 0 ? 0 : successes / rows.length,
    tokens: rows.reduce((total, row) => total + Number(row[4] ?? 0), 0),
  };
}

export function summarizeEvaluation(csv: string): EvaluationSummary {
  const rows = csv
    .split('\n')
    .map((text) => text.trim())
    .filter((text) => text !== '' && !text.startsWith('task,'))
    .map((text) => text.split(',').map((cell) => cell.trim()));

  for (const row of rows) {
    if (row.length !== 5 || ![
      'with',
      'without',
    ].includes(row[1] ?? '') || ![
      '0',
      '1',
    ].includes(row[3] ?? '') || Number.isNaN(Number(row[4]))) {
      throw new Error(`Bad row: ${row.join(',')}`);
    }
  }
  const withBase = summarize(rows.filter((row) => row[1] === 'with'));
  const withoutBase = summarize(rows.filter((row) => row[1] === 'without'));

  return {
    with: withBase,
    without: withoutBase,
    passes: withBase.successRate > withoutBase.successRate && withBase.tokens <= withoutBase.tokens,
  };
}

function line(name: string, summary: ConditionSummary): string {
  return `${name}: ${String(summary.successes)}/${String(summary.runs)} successes (${(summary.successRate * 100).toFixed(0)} %), ${String(summary.tokens)} tokens\n`;
}

function main(): void {
  const file = process.argv[2];

  if (file === undefined) {
    process.stderr.write('Usage: node scripts/evaluation-summary.ts <results.csv>\n');
    process.exitCode = 2;
    return;
  }
  const summary = summarizeEvaluation(readFileSync(file, 'utf8'));

  process.stdout.write(line('With the base', summary.with));
  process.stdout.write(line('Without the base', summary.without));
  process.stdout.write(summary.passes ? 'Evaluation passed: better with the base, with no more tokens.\n' : 'Evaluation failed: not better with the base, or more tokens.\n');
  process.exitCode = summary.passes ? 0 : 1;
}

// Writes the fields that the local header and the central directory share, from `at` on:
// version needed, flags, method (8, deflate), time, date, CRC, both sizes, name length.
function writeCommon(header: Buffer, at: number, entry: ZipFields): void {
  header.writeUInt16LE(20, at);
  header.writeUInt16LE(entry.flags, at + 2);
  header.writeUInt16LE(8, at + 4);
  header.writeUInt16LE(DOS_DATE, at + 8);
  header.writeUInt32LE(crc32(entry.data), at + 10);
  header.writeUInt32LE(entry.compressed.length, at + 14);
  header.writeUInt32LE(entry.data.length, at + 18);
  header.writeUInt16LE(entry.name.length, at + 22);
}

export function zip(files: Record<string, string | Buffer>, options: ZipOptions = {}): Buffer {
  const locals: Buffer[] = [];
  const centrals: Buffer[] = [];
  const flags = UTF8_NAMES | (options.encrypted === true ? 1 : 0);
  let offset = 0;

  for (const [
    name,
    content,
  ] of Object.entries(files)) {
    const data = Buffer.isBuffer(content) ? content : Buffer.from(content, 'utf8');
    const entry: ZipFields = {
      flags,
      data,
      compressed: deflateRawSync(data),
      name: Buffer.from(name, 'utf8'),
    };
    const local = Buffer.alloc(30);
    const central = Buffer.alloc(46);

    local.writeUInt32LE(0x04_03_4B_50, 0);
    writeCommon(local, 4, entry);
    central.writeUInt32LE(0x02_01_4B_50, 0);
    central.writeUInt16LE(20, 4);
    writeCommon(central, 6, entry);
    central.writeUInt32LE(offset, 42);
    locals.push(local, entry.name, entry.compressed);
    centrals.push(central, entry.name);
    offset += local.length + entry.name.length + entry.compressed.length;
  }
  const directory = Buffer.concat(centrals);

  return Buffer.concat([
    ...locals,
    directory,
    endRecord(Object.keys(files).length, directory.length, offset),
  ]);
}

function endRecord(count: number, directorySize: number, directoryOffset: number): Buffer {

  end.writeUInt16LE(count, 8);
  end.writeUInt16LE(count, 10);
  end.writeUInt32LE(directorySize, 12);
  end.writeUInt32LE(directoryOffset, 16);
  return end;
}

## 1. C (embedded)

```c
#define REG32(addr) (*(volatile uint32_t *)(addr))
#define PUMP_CTRL   REG32(0x40002000u)

void SysTick_Handler(void)
{
    if (PUMP_CTRL & (1u << 2)) {
        PUMP_CTRL &= ~(1u << 2);
    }
}
```

Expected: `SysTick_Handler` is called by the hardware (never "dead code"); `PUMP_CTRL` is a macro on
a hardware register; bit 2 is read then cleared; what bit 2 means is "not visible in this excerpt".

## 2. C++

```cpp
std::unique_ptr<Valve> make_valve(std::string tag) {
    auto valve = std::make_unique<Valve>(std::move(tag));
    return valve;
}
```

Expected: one owner, moved out on return; `std::move(tag)` casts, the constructor moves; `Valve`
and its constructor are "not visible in this excerpt".

## 3. Java

```java
@Service
@RequiredArgsConstructor
public class PumpService {
    private final PumpRepository repository;
}
```

Expected: Spring creates the object and injects `repository`; Lombok generates the constructor;

fn read_level(path: &str) -> Result<f64, std::io::Error> {

Expected: `?` returns the error at once (not `?.`); `unwrap_or(0.0)` gives 0.0 when parsing fails.
