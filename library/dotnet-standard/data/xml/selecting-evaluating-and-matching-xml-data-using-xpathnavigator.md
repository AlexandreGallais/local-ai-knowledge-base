# Selecting, Evaluating and Matching XML Data using XPathNavigator

The `System.Xml.XPath.XPathNavigator` class provides methods to select nodes in an `System.Xml.XPath.XPathDocument` or `System.Xml.XmlDocument` object using an XPath query, evaluate and examine the results of an XPath expression, and determine if a node in an `System.Xml.XPath.XPathDocument` or `System.Xml.XmlDocument` object matches a given XPath expression. These and other concepts that relate to selecting, evaluating and matching nodes in an `System.Xml.XPath.XPathDocument` or `System.Xml.XmlDocument` object are described in the following topics.

## In This Section

 Select XML Data Using XPathNavigator
 Describes the set of `System.Xml.XPath.XPathNavigator` class methods used to select a set of nodes in an `System.Xml.XPath.XPathDocument` or `System.Xml.XmlDocument` object using an XPath expression.

 Evaluate XPath Expressions using XPathNavigator
 Describes the `System.Xml.XPath.XPathNavigator.Evaluate*` method of the `System.Xml.XPath.XPathNavigator` class used to evaluate an XPath expression.

 Matching Nodes using XPathNavigator
 Describes the `System.Xml.XPath.XPathNavigator.Matches*` method of the `System.Xml.XPath.XPathNavigator` class used to determine if a node matches an XPath expression.

 Node Types Recognized with XPath Queries
 Describes the types of nodes recognized in an XPath query.

 XPath Queries and Namespaces
 Describes the use of namespaces in an XPath query.

 Compiled XPath Expressions
 Describes the `System.Xml.XPath.XPathExpression` class that represents a compiled XPath query.
