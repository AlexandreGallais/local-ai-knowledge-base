# ASP.NET Core Built-in Tag Helpers Sample

This sample illustrates variations of the built-in Tag Helpers with both MVC and Razor Pages:

* Anchor Tag Helper
  * `asp-action`
  * `asp-all-route-data`
  * `asp-area`
  - asp-controller
  - asp-fragment
  - asp-host
  - asp-page
  - asp-page-handler
  * `asp-protocol`
  * `asp-route`
  * `asp-route-{value}`
* Partial Tag Helper
  -* `for`
  * `model`
  * `name`
  - view-data
