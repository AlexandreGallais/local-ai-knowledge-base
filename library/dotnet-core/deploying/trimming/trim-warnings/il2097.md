# IL2097: Field annotated with 'DynamicallyAccessedMembersAttribute' is not of type 'System.Type', 'System.String', or derived

## Cause

`System.Diagnostics.CodeAnalysis.DynamicallyAccessedMembersAttribute` is only applicable to items of type `System.Type`, `System.String`, or derived. On all other types the attribute will be ignored. Using the attribute on any other type is likely incorrect and unintentional.

## Example

```csharp
// IL2097: Field '_valueField' has 'DynamicallyAccessedMembersAttribute', but that attribute can only be applied to fields of type 'System.Type' or 'System.String'
[DynamicallyAccessedMembers(DynamicallyAccessedMemberTypes.PublicMethods)]
object _valueField;
}
```
