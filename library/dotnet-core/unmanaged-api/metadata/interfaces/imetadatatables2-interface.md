# IMetaDataTables2 Interface

Extends IMetaDataTables to include methods for working with metadata streams.

## Methods

| Method | Description |
|------------|-----------------|
|GetMetaDataStorage Method| Gets the size and contents of the metadata stored in the specified section. |
|GetMetaDataStreamInfo Method| Gets the name, size, and contents of the metadata stream at the specified index. |

## Requirements

 **Platforms:** See .NET supported operating systems.

 **Header:** Cor.h

 **Library:** CorGuids.lib

 **.NET versions:** Available since .NET Framework 2.0
