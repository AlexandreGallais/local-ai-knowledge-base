# Pod Security Policy

A former Kubernetes API that enforced security restrictions during pod creation and updates.

PodSecurityPolicy was deprecated as of Kubernetes v1.21, and removed in v1.25.
As an alternative, use Pod Security Admission or a 3rd party admission plugin.
