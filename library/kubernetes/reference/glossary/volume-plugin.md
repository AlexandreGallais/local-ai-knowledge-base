# Volume Plugin

A Volume Plugin enables integration of storage within a Pod.

A Volume Plugin lets you attach and mount storage volumes for use by a Pod. Volume plugins can be _in tree_ or _out of tree_. _In tree_ plugins are part of the Kubernetes code repository and follow its release cycle. _Out of tree_ plugins are developed independently.
