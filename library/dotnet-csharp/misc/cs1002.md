# Compiler Error CS1002

; expected

 The compiler detected a missing semicolon. A semicolon terminates many C# statements, including declarations, assignments, expression statements, and `return` statements. Blocks and control statements such as `if`, `for`, and `while` don't end with a semicolon. A statement can span more than one line.

 The following sample generates CS1002:

```csharp
// CS1002.cs  
namespace x  
{  
   abstract public class clx  
   {  
      int i   // CS1002, missing semicolon  
  
      public static int Main()  
      {  
         return 0;  
      }  
   }  
}  
```
