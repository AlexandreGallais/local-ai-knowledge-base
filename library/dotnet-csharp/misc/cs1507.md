# Compiler Error CS1507

Cannot link resource file 'file' when building a module

 **/linkresource** was used in the same compilation with the **module** option on the **OutputType**, which is not allowed. For example, the following options would generate CS1507:

```console
csc /linkresource:rf.resource /target:module in.cs  
```  

 Embedding resources (**EmbeddedResource**), however, is allowed.
