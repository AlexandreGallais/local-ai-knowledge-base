# Official documentation of Markdown and diagrams

1. Before you write a Mermaid diagram, a Graphviz graph, a D2 diagram or a Vega-Lite chart, check its syntax with the `markdown-official-docs` server: `search_docs`, then `read_doc` on one section.
2. It holds Mermaid, the CommonMark and GitHub Flavored Markdown specifications, the Pandoc User's Guide, the markdownlint rules, KaTeX, Vega-Lite, Graphviz and D2.
3. Search a Mermaid diagram by its keyword, as `sequenceDiagram` or `flowchart`; a markdownlint rule by its code, as `MD013`; a Graphviz attribute by its name, as `rankdir`.
4. Read one section at a time. Never read the folder `.agents/mcp/markdown-official-docs/library/` by hand.
