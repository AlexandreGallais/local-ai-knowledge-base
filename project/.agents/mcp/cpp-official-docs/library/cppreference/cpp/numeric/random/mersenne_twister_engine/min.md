# std::mersenne_twister_engine<UIntType,w,n,m,r,a,u,d,s,b,t,c,l,f>::min

`static constexpr result_type min();` (since C++11)

Returns the minimum value potentially generated by the random-number engine.

### Return value

`0u`

Constant.
