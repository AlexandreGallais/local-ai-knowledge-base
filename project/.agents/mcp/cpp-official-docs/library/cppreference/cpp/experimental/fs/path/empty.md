# std::experimental::filesystem::path::empty

`bool empty() const;` (filesystem TS)

Checks if the path is empty.

### Parameters

(none)

### Return value

`true` if the path is empty, `false` otherwise.

### Exceptions

`noexcept` specification:

`noexcept`
