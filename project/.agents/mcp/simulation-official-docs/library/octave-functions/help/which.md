@deftypefn  {} {} which @var{name} @dots{}
@deftypefnx {} {[@var{str}, @dots{}] =} which ('@var{name}', @dots{})
Display the type of each @var{name}.

If @var{name} is defined from a function file, the full name of the file is
also displayed.
@seealso{help, lookfor}
@end deftypefn
