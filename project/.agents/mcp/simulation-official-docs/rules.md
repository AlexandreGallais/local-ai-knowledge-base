# Official documentation of simulation

1. When your memory of Modelica, FMI, SSP or Octave is not sure, look it up with the `simulation-official-docs` server: `search_docs`, then `read_doc` on one section.
2. It holds the Modelica language specification, the FMI 3.0 and SSP 2.0 standards, the GNU Octave manual and the help of each Octave function.
3. Search a function of FMI by its name, as `fmi3DoStep`, a word of Modelica, as `connector`, an Octave function, as `ode45`.
4. Octave is close to MATLAB, not the same: say so when you explain MATLAB code from the Octave documentation.
5. MATLAB, Simulink, Simscape and Stateflow are not in the base: their documentation is not free. Say so; never invent their API.
6. Read one section at a time. Never read the folder `.agents/mcp/simulation-official-docs/library/` by hand.
