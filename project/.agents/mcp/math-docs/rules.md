# Official documentation of mathematics

1. When your memory of mathematics is not sure, look it up with the `math-docs` server: `search_docs`, then `read_doc` on one section.
2. It holds free textbooks in their own source format (LaTeX, PreTeXt, XML): linear algebra (Hefferon, Austin, Beezer), discrete mathematics (Levin) and combinatorics (Keller and Trotter).
3. Before a calculation (a matrix, a rotation, an angle, a count), look the definition and a worked example up in these books, then work the calculation out step by step.
4. The formulas are written in LaTeX, as the books write them: read `\cos\theta` as cos θ.
5. Read one section at a time. Never read the folder `.agents/mcp/math-docs/library/` by hand.
