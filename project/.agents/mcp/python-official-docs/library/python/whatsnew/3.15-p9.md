# What's new in Python 3.15 (part 9 of 9)

## Notable changes in 3.15.2

### importlib

- Threads that simultaneously perform first-time `import package.submodule`
imports no longer risk a deadlock or spurious import errors, a regression
introduced in 3.15.0 by the fix for 83065.  A package's import lock is
now released as soon as its `__init__` returns.
`importlib.import_module()` now returns the partially initialized
module in a circular import split across threads, as the `import`
statement already did, instead of raising `_DeadlockError`.
(Contributed by Gregory P. Smith in 159963.)

### ssl

- The `ssl` module now rejects TLS certificate chains that contain one
of a set of compromised eMudhra intermediate CA certificates.  The affected
certificates are identified by their public key, so cross-signed copies that
reuse the same key are blocked as well.  It is a defense-in-depth backstop
that applies even when an application supplies its own root CA bundle, and
regardless of whether the platform trust store has removed trust.
(Contributed by Christian Heimes in 160040 for 2026-115557.)
