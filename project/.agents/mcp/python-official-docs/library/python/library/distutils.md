# `distutils` --- Building and installing Python modules

Module `distutils`.

> *Deprecated since version 3.10, removed in version 3.12.*

This module is no longer part of the Python standard library.
It was removed in Python 3.12 after
being deprecated in Python 3.10.  The removal was decided in PEP 632,
which has `migration advice
<https://peps.python.org/pep-0632/#migration-advice>`_.

The last version of Python that provided the `distutils` module was
Python 3.11.
