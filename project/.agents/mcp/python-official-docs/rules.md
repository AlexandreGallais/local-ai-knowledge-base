# Official documentation of Python and of the Inkscape extensions

1. When your memory of a Python API is not sure, look it up with the `python-official-docs` server: `search_docs`, then `read_doc` on one section.
2. It holds the Python language reference, the standard library, the tutorial, the how-to guides, the FAQ and what is new in each version, and the `inkex` API of the Inkscape extensions with the guides for extension authors.
3. Search a module or a class by its name, as `pathlib` or `PathElement`; narrow the search with `tool` `inkex` for an Inkscape extension.
4. Read one section at a time. Never read the folder `.agents/mcp/python-official-docs/library/` by hand.
5. Trust the documentation more than your memory. Check the version of Python the project uses before you use a new API.
