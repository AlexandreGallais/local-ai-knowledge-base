# Official documentation of Linux

1. When your memory of Linux, Fedora, GNOME or Wayland is not sure, look it up with the `linux-official-docs` server: `search_docs`, then `read_doc` on one section.
2. It holds Fedora (Quick Docs, release notes, DNF5, RPM), the Linux man-pages, systemd, util-linux, the kernel administration guide, GNOME (developer documentation, GTK 4, GLib, GJS), Wayland and its protocols, PipeWire, Flatpak and the SELinux Notebook.
3. Search a system call or a C function by its name, as `open` or `epoll_wait`; a systemd unit setting by its name, as `ExecStart` or `systemd.service`; a Wayland interface by its name, as `wl_surface`.
4. On Fedora, use `dnf`, not `apt` or `yum`: check the command in the documentation of DNF5.
5. Read one section at a time. Never read the folder `.agents/mcp/linux-official-docs/library/` by hand.
