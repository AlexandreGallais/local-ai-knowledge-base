# Compiler Warning (level 2) CS0618

'member' is obsolete: 'text'

A member was marked with the `Obsolete` attribute, such that a warning will be issued when the member is referenced. For more information, see Assembly level attributes.

The following sample generates CS0618:

```csharp
// CS0618.cs
// compile with: /W:2
using System;

public class C
{
   [Obsolete("Use newMethod instead", false)]   // warn if referenced
   public static void m2()
   {
   }

   public static void newMethod()
   {
   }
}

class MyClass
{
   public static void Main()
   {
      C.m2();  // CS0618
   }
}
```
