# Compiler Error CS1013

Invalid number

 The compiler detected a malformed number. For more information on integral types, see the Integral Types Table.

## Example

 The following sample generates CS1013:

```csharp
// CS1013.cs  
class Sample  
{  
    static void Main()  
    {  
        int i = 0x;   // CS1013  
    }  
}  
```
