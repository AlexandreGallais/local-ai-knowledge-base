# Compiler Error CS1906

Invalid option 'option'; Resource visibility must be either 'public' or 'private'

 This error indicates an invalid use of the **/resource** or **/linkresource** command-line option. For more information, see **EmbeddedResource** (Embed Resource File to Output) and **LinkResource** (Link to .NET Framework Resource). Check the syntax of the **/resource** or **/linkresource** command-line option, and make sure that the accessibility modifier used is either **public** or `private`.
