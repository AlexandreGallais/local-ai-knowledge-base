# Compiler Error CS1542

'dll' cannot be added to this assembly because it already is an assembly; use '/R' option instead

 The file that was referenced with the **AddModules** compiler option was not built with **module** element of the **OutputType** compiler option; use **References** to reference the file in this compilation.
