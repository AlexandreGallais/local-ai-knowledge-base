# Compiler Error CS1909

The DefaultParameterValue attribute is not applicable on parameters of type 'type'

 CS1909 is generated when you use a `System.Runtime.InteropServices.DefaultParameterValueAttribute` attribute that is not applicable on the parameter type. This error message is no longer emitted, see CS1910 for more information.
