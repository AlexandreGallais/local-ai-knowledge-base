# MediaTypeNames+Application class

Namespace: `System.Net.Mime`

```csharp
public static class MediaTypeNames.Application
```

Specifies the kind of application data in an email message attachment.

#### Remarks
The `Application` media type designates that the attachment data should be processed by an application, such as a Postscript processor, a spreadsheet, or a word processor. The data is usually something other than simple text, such as an image, or an audio or video file.
