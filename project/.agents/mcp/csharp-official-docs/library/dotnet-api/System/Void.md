# Void struct

Namespace: `System`

```csharp
public struct Void
```

Specifies a return value type for a method that does not return a value.

#### Remarks
The `Void` structure is used in the `Reflection` namespace, but is rarely useful in a typical application. The `Void` structure has no members other than the ones all types inherit from the `Object` class.
