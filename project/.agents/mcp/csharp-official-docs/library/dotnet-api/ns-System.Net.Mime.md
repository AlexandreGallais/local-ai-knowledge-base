# System.Net.Mime namespace

Contains types that are used to represent Multipurpose Internet Mail Exchange (MIME) headers. These types are used with the types in the `Mail` namespace to specify Content-Type, Content-Disposition, and Content-transfer-Encoding headers when using the `SmtpClient` class to send email.

#### Remarks
MIME data is represented by the `Attachment` class.
