# CorrelationManager class

Namespace: `System.Diagnostics`

```csharp
public class CorrelationManager
```

Correlates traces that are part of a logical transaction.

#### Remarks
Traces generated from a single logical operation can be tagged with an operation-unique identity, in order to distinguish them from traces from a different logical operation. For example, it may be useful to group correlated traces by ASP.NET request. The `CorrelationManager` class provides methods used to store a logical operation identity in a thread-bound context and automatically tag each trace event generated by the thread with the stored identity.

Logical operations can also be nested. The `LogicalOperationStack` property exposes the stack of nested logical operation identities. Each call to the `CorrelationManager.StartLogicalOperation` method pushes a new logical operation identity onto the stack. Each call to the `CorrelationManager.StopLogicalOperation` method pops a logical operation identity off the stack.

> **Note:**
>  Logical operation identities are objects, allowing the use of a type for a logical operation identity.

## CorrelationManager.ActivityId property

```csharp
public Guid ActivityId { get; set; }
```

Gets or sets the identity for a global activity.

Returns: A `Guid` structure that identifies the global activity.

#### Remarks
The `ActivityId` property gets and sets the global activity identity in the `CallContext` for the thread. The `CorrelationManager.ActivityId` is used for trace transfer operations in trace listeners that override the `TraceListener.TraceTransfer` method, such as the `XmlWriterTraceListener` class.

## CorrelationManager.LogicalOperationStack property

```csharp
public System.Collections.Stack LogicalOperationStack { get; }
```

Gets the logical operation stack from the call context.

Returns: A `Stack` object that represents the logical operation stack for the call context.

#### Remarks
Each call to the `CorrelationManager.StartLogicalOperation` method pushes a new logical operation identity onto the `LogicalOperationStack` property's stack. Each call to the `CorrelationManager.StopLogicalOperation` method pops a logical operation identity from the stack.

## CorrelationManager.StartLogicalOperation() method

```csharp
public void StartLogicalOperation ();
```

Starts a logical operation on a thread.

#### Remarks
The logical operation is started using an automatically generated GUID for a logical operation identifier.

## CorrelationManager.StartLogicalOperation(Object) method

```csharp
public void StartLogicalOperation (object operationId);
```

Starts a logical operation with the specified identity on a thread.

Parameters:

- `operationId`: An object identifying the operation.

Exceptions:

- `ArgumentNullException`: The `operationId` parameter is `null`.

#### Remarks
The `operationId` parameter can be any object, such as a `String` that allows the operation to be identified for tracing purposes. The object represented by `operationId` is added to the `LogicalOperationStack` property.

## CorrelationManager.StopLogicalOperation() method

```csharp
public void StopLogicalOperation ();
```

Stops the current logical operation.

Exceptions:

- `InvalidOperationException`: The `CorrelationManager.LogicalOperationStack` property is an empty stack.

#### Remarks
The logical operation is halted and the logical operation identity is removed from the `LogicalOperationStack` property.
