# System.Net namespace

Provides a simple programming interface for many of the protocols used on networks today.

Classes in the `Net` namespace can be used to develop Windows Store apps or desktop apps. When used in a Windows Store app, classes in the `Net` namespace are affected by network isolation feature, part of the application security model used by the Windows Developer Preview. The appropriate network capabilities must be enabled in the app manifest for a Windows Store app for the system to allow network access by a Windows Store app. For more information, see the Network Isolation for Windows Store Apps.
