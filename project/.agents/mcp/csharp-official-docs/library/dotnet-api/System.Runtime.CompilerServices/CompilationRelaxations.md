# CompilationRelaxations enum

Namespace: `System.Runtime.CompilerServices`

```csharp
public enum CompilationRelaxations
```

Specifies parameters that control the strictness of the code generated by the common language runtime's just-in-time (JIT) compiler.

#### Remarks
Use the `CompilationRelaxations` enumeration with the `CompilationRelaxationsAttribute` attribute.

## CompilationRelaxations.NoStringInterning field

```csharp
NoStringInterning
```

Marks an assembly as not requiring string-literal interning. The common language runtime creates one string object for each unique string literal, rather than making multiple copies. This behavior, called string interning, internally requires building auxiliary tables that consume memory resources.
