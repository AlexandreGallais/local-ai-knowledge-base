# ECDiffieHellmanKeyDerivationFunction enum

Namespace: `System.Security.Cryptography`

```csharp
public enum ECDiffieHellmanKeyDerivationFunction
```

Specifies the key <example-value> function that the `ECDiffieHellmanCng` class will use to convert secret <example-value> into key material.

#### Remarks
The `ECDiffieHellmanKeyDerivationFunction` enumeration defines the type of algorithm that will be used to transform a raw secret <example-value> into key material. The secret <example-value> is the value that is generated from a private key and the other party's public key, as part of the key exchange. It is the seed value for the key <example-value> that is generated by the `ECDiffieHellmanCng.DeriveKeyMaterial` method.

The `KeyDerivationFunction` property uses this enumeration to get the key <example-value> function for the `ECDiffieHellmanCng` class.

## ECDiffieHellmanKeyDerivationFunction.Hash field

```csharp
Hash
```

A hash algorithm is used to generate key material. The `ECDiffieHellmanCng.HashAlgorithm` property specifies the name of the algorithm to use. If the algorithm name is not specified, `SHA256` is used as the default algorithm. You can also specify the `ECDiffieHellmanCng.SecretPrepend` and `ECDiffieHellmanCng.SecretAppend` properties, but they are not required. The amount of key <example-value> that is generated is equivalent to the size of the hash value for the specified algorithm.

## ECDiffieHellmanKeyDerivationFunction.Hmac field

```csharp
Hmac
```

A Hash-based Message Authentication Code (HMAC) algorithm is used to generate key material. The `ECDiffieHellmanCng.HmacKey` property specifies the key to use. Either this property must be set or the `ECDiffieHellmanCng.UseSecretAgreementAsHmacKey` property must be set to `true`; otherwise, a `CryptographicException` is thrown when you use `ECDiffieHellmanKeyDerivationFunction.Hmac`. If both properties are set, the secret <example-value> is used as the HMAC key. You can also specify the `ECDiffieHellmanCng.SecretPrepend` and `ECDiffieHellmanCng.SecretAppend` properties, but they are not required. The amount of key <example-value> that is generated is equivalent to the size of the HMAC value.

## ECDiffieHellmanKeyDerivationFunction.Tls field

```csharp
Tls
```

The Transport Layer Security (TLS) protocol is used to generate key material. The `ECDiffieHellmanCng.Seed` and `ECDiffieHellmanCng.Label` properties must be set; otherwise, a `CryptographicException` is thrown when you use `ECDiffieHellmanKeyDerivationFunction.Tls`. This value generates 160 bits of key material.
