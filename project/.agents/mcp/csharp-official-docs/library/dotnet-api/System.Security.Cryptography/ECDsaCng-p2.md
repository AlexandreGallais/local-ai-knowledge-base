# ECDsaCng class (part 2 of 2)

## ECDsaCng.SignData(Byte[]) method

```csharp
public byte[] SignData (byte[] data);
```

Generates a signature for the specified data.

Parameters:

- `data`: The message data to be signed.

Returns: A digital signature for the specified data.

Exceptions:

- `ArgumentNullException`: `data` is `null`.
- `CryptographicException`: The key <example-value> that is associated with the instance does not have a private key.

#### Remarks
This method generates a signature for the specified data by hashing the input data using the `HashAlgorithm` property, and then signing the result.

The `Sign` flag is required if the Cryptography Next Generation (CNG) key is not randomly generated by the `ECDsaCng` object.
