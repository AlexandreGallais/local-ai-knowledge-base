# PbeEncryptionAlgorithm enum

Namespace: `System.Security.Cryptography`

```csharp
public enum PbeEncryptionAlgorithm
```

Specifies encryption algorithms to be used with Password-Based Encryption (PBE).

To be added.

## PbeEncryptionAlgorithm.Aes128Cbc field

```csharp
Aes128Cbc
```

Indicates the encryption should be performed with the AES-128 algorithm in CBC mode with PKCS#7 padding.

## PbeEncryptionAlgorithm.Aes192Cbc field

```csharp
Aes192Cbc
```

Indicates the encryption should be performed with the AES-192 algorithm in CBC mode with PKCS#7 padding.

## PbeEncryptionAlgorithm.Aes256Cbc field

```csharp
Aes256Cbc
```

Indicates that encryption be performed with the AES-256 algorithm in CBC mode with PKCS#7 padding.

## PbeEncryptionAlgorithm.TripleDes3KeyPkcs12 field

```csharp
TripleDes3KeyPkcs12
```

Indicates the encryption should be performed with the TripleDES algorithm in CBC mode with a 192-bit key <example-value> using the Key <example-value> Function (KDF) from PKCS#12.

## PbeEncryptionAlgorithm.Unknown field

```csharp
Unknown
```

Indicates that no encryption algorithm has been selected.
