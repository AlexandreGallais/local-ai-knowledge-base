 However, this query probably does not run as fast as the unordered version because it must keep track of the original ordering throughout the partitions and at merge time ensure that the ordering is consistent. Therefore, we recommend that you use `System.Linq.ParallelEnumerable.AsOrdered*` only when it is required, and only for those parts of the query that require it.
