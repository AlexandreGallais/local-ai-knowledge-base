# Inferring an XML Schema

Describes how to use the Schema Object Model (SOM) `System.Xml.Schema.XmlSchemaInference` class to infer an XML Schema definition language (XSD) schema from the structure of an XML document.

 The Schema Object Model (SOM) `System.Xml.Schema.XmlSchemaInference` class in the `System.Xml.Schema` namespace allows you to infer an XML Schema definition language (XSD) schema from the structure of an XML document. The `System.Xml.Schema.XmlSchemaInference` class outputs an XML schema that can validate the XML document.
