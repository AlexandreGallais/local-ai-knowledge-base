# Editing XML Data using XPathNavigator

The `System.Xml.XPath.XPathNavigator` class provides methods to insert, modify and remove nodes and values from an XML document contained in an `System.Xml.XmlDocument` object. In order to use any of these methods to insert, modify, and remove nodes and values, the `System.Xml.XPath.XPathNavigator` object must be editable, that is, its `System.Xml.XPath.XPathNavigator.CanEdit` property must be true.

## In This Section

 Insert XML Data using XPathNavigator
 Describes how to insert sibling, child, attribute nodes and values in to an `System.Xml.XmlDocument` object using the `System.Xml.XPath.XPathNavigator` class.

 Modify XML Data using XPathNavigator
 Describes how to modify nodes and values in an `System.Xml.XmlDocument` object using the `System.Xml.XPath.XPathNavigator` class.

 Remove XML Data using XPathNavigator
 Describes how to remove nodes and values from an `System.Xml.XmlDocument` object using the `System.Xml.XPath.XPathNavigator` class.
