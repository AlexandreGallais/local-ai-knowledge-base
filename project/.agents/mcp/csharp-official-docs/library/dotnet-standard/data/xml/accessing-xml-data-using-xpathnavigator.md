# Accessing XML Data using XPathNavigator

The `System.Xml.XPath.XPathNavigator` class provides methods to navigate nodes, extract XML data and access strongly typed XML data in an `System.Xml.XPath.XPathDocument` or `System.Xml.XmlDocument` object.

## In This Section

 Node Set Navigation Using XPathNavigator
 Describes the node set navigation methods of the `System.Xml.XPath.XPathNavigator` class used to navigate nodes in an `System.Xml.XPath.XPathDocument` or `System.Xml.XmlDocument` object.

 Attribute and Namespace Node Navigation Using XPathNavigator
 Describes the attribute and namespace node navigation methods of the `System.Xml.XPath.XPathNavigator` class.

 Extract XML Data Using XPathNavigator
 Describes the various methods of extracting XML data from an `System.Xml.XPath.XPathDocument` or `System.Xml.XmlDocument` object.

 Accessing Strongly Typed XML Data Using XPathNavigator
 Describes accessing strongly typed XML data in an `System.Xml.XPath.XPathDocument` or `System.Xml.XmlDocument` object using the `System.Xml.XPath.XPathNavigator` class.

 User Defined Functions and Variables
 Describes implementing a custom `System.Xml.Xsl.XsltContext` class along with the interfaces `System.Xml.Xsl.IXsltContextFunction` and `System.Xml.Xsl.IXsltContextVariable` that support extension functions and variables.
