# ASP0021: The return type of the BindAsync method must be `ValueTask<T>`.

|                                     | Value        |
| -                                   | -            |
| **Rule ID**                         | ASP0021      |
| **Category**                        | Usage        |
| **Fix is breaking or non-breaking** | Non-breaking |

## Cause

An implementation of the `Microsoft.AspNetCore.Http.IBindableFromHttpContext`1.BindAsync*` method has a return type that isn't `System.Threading.Tasks.ValueTask`1`.

## Rule description

This diagnostic is emitted when an implementation of the `BindAsync` method has a return type that isn't `ValueTask<T>`.

## How to fix violations

To fix a violation of this rule, define a `ValueTask<T>` return type for `BindAsync` and consider implementing `Microsoft.AspNetCore.Http.IBindableFromHttpContext`1` to enforce implementation.

## When to suppress warnings

Do not suppress a warning from this rule.
