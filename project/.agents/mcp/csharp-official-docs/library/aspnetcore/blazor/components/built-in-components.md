# ASP.NET Core built-in Razor components

The following built-in Razor components are provided by the Blazor framework. For information on non-security-related project template components, see ASP.NET Core Blazor project structure. For information on security-related project template components, see the Security node articles.

* `AntiforgeryToken`
* `AuthorizeView`
* `CacheView`
* `CascadingValue`
* `DataAnnotationsValidator`
* `DynamicComponent`
* `Editor<T>`
* `EditForm`
* `ErrorBoundary`
* `FocusOnNavigate`
* `HeadContent`
* `HeadOutlet`
* `ImportMap`
* `InputCheckbox`
* `InputDate`
* `InputFile`
* `InputNumber`
* `InputRadio`
* `InputRadioGroup`
* `InputSelect`
* `InputText`
* `InputTextArea`
* `LayoutComponentBase`
* `LayoutView`
* `NavigationLock`
* `NavLink`
* `PageTitle`
* `OwningComponentBase`
* `Paginator`
* `QuickGrid`
* `Router`
* `RouteView`
* `SectionContent`
* `SectionOutlet`
* `ValidationMessage`
* `ValidationSummary`
* `Virtualize`
