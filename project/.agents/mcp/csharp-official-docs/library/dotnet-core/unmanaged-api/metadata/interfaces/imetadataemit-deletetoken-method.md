# IMetaDataEmit::DeleteToken <example-value>

Deletes the specified token from the current metadata scope.

## Syntax

```cpp
HRESULT DeleteToken (
    [in]  mdToken     tkObj
);
```

## Parameters

 `tkObj`
 [in] The token to be deleted.
