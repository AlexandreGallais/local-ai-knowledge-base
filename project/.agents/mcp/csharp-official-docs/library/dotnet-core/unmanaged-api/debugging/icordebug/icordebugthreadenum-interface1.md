# ICorDebugThreadEnum Interface

Implements ICorDebugEnum methods and enumerates ICorDebugThread arrays.

## Methods

|Method|Description|
|------------|-----------------|
|Next Method|Gets the specified number of `ICorDebugThread` instances from the enumeration, starting at the current position.|

## Remarks

> **Note:**
> This interface does not support being called remotely, either cross-machine or cross-process.

## Requirements

 **Platforms:** See .NET supported operating systems.

 **Header:** CorDebug.idl, CorDebug.h

 **Library:** CorGuids.lib

 **.NET versions:** Available since .NET Framework 1.0
