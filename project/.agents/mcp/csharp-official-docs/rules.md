# Official documentation of C# and .NET

1. When your memory of a C# or .NET API is not sure, look it up with the `csharp-official-docs` server: `search_docs`, then `read_doc` on one section.
2. It holds the C# language, the .NET guides and fundamentals (dependency injection, configuration, logging, the CA and IDE analysis rules), the architecture guides, ASP.NET Core, EF Core, .NET Aspire, and the API reference of the base class library, of ASP.NET Core and of EF Core.
3. Search a type by its name, as `List<T>` or `DbContext`, and a member as `List<T> Add`.
4. Read one section at a time. Never read the folder `.agents/mcp/csharp-official-docs/library/` by hand.
5. Trust the documentation more than your memory. Check the version of .NET in the `TargetFramework` of the project before you use a new API.
