# Official documentation of GitLab CI/CD

1. When your memory of GitLab CI/CD is not sure, look it up with the `gitlab-official-docs` server: `search_docs`, then `read_doc` on one section.
2. It holds the folder `doc/ci` of the GitLab documentation (`.gitlab-ci.yml` and the reference of every keyword), the documentation of GitLab Runner, the Dev Containers CLI and glab, the GitLab CLI (every `glab` command).
3. Search a keyword of `.gitlab-ci.yml` by its name, as `rules` or `artifacts`, then read its section in the keyword reference.
4. Read one section at a time. Never read the folder `.agents/mcp/gitlab-official-docs/library/` by hand.
