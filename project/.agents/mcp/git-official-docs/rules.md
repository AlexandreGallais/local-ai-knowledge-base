# Official documentation of Git

1. When your memory of Git is not sure, look it up with the `git-official-docs` server: `search_docs`, then `read_doc` on one section.
2. It holds the manual page of every git command and the guides of the Git documentation.
3. Search a command by its name, as `git rebase`, then read the section you need: SYNOPSIS, DESCRIPTION, OPTIONS, EXAMPLES.
4. Read one section at a time. Never read the folder `.agents/mcp/git-official-docs/library/` by hand.
