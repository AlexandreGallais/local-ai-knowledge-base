# SyntheticAttribute interface (java.lang.classfile.attribute)

```java
public sealed interface SyntheticAttribute extends Attribute<SyntheticAttribute>, ClassElement, MethodElement, FieldElement permits BoundAttribute.BoundSyntheticAttribute, UnboundAttribute.UnboundSyntheticAttribute
```

Models the Synthetic attribute (JVMS ), which marks a class member as implementation-specific artifacts.

This attribute can appear on classes, methods, and fields, and permits
multiple instances in a structure.
It has no data dependency.

This attribute was introduced in the Java SE Platform version 1.1, major
version `ClassFile#JAVA_1_VERSION`.

**API note:** This attribute has been largely superseded by the ACC_SYNTHETIC modifier in newer `class` files.  See `java.compiler/javax.lang.model.util.Elements.Origin` for a more in-depth
description about the differences between synthetic and implicit (mandated)
constructs generated by compilers.
