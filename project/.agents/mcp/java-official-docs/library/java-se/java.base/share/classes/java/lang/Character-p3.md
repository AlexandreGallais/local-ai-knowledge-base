## Character.SURROGATES_AREA

```java
public static final UnicodeBlock SURROGATES_AREA
```

**Deprecated:** Instead of `SURROGATES_AREA`, use `HIGH_SURROGATES`,
`HIGH_PRIVATE_USE_SURROGATES`, and `LOW_SURROGATES`.
These constants match the block definitions of the Unicode Standard.
The `of(char)` and `of(int)` methods return the
standard constants.
