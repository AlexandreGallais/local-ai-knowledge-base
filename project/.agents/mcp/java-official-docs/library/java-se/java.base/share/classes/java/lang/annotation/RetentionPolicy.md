# RetentionPolicy enum (java.lang.annotation)

```java
public enum RetentionPolicy
```

Annotation retention policy.  The constants of this enumerated class
describe the various policies for retaining annotations.  They are used
in conjunction with the `Retention` meta-annotation interface to
specify how long annotations are to be retained.

**Since:** 1.5
