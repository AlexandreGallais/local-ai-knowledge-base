# CRLReason enum (java.security.cert)

```java
public enum CRLReason
```

The CRLReason enumeration specifies the reason that a certificate
is revoked, as defined in
RFC 5280: Internet X.509 Public Key <example-value> Certificate and CRL
Profile.

**Since:** 1.7

**See also:** X509CRLEntry#getRevocationReason

**See also:** CertificateRevokedException#getRevocationReason
