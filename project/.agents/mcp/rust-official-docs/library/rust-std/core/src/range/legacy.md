# core::range::legacy

#### Legacy range types

The types within this module will be replaced by the types
`Range`, `RangeInclusive`, `RangeToInclusive`, and `RangeFrom` in the parent
module, `core::range`.

The types here are equivalent to those in `core::ops`.
