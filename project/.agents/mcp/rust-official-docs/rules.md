# Official documentation of Rust

1. When your memory of a Rust API is not sure, look it up with the `rust-official-docs` server: `search_docs`, then `read_doc` on one section.
2. It holds The Rust Programming Language (the book), The Rust Reference, Rust by Example, the Cargo book, and the standard library: `core`, `alloc` and `std`.
3. Search a type by its name, as `Vec`, and a method as `Vec push`.
4. Read one section at a time. Never read the folder `.agents/mcp/rust-official-docs/library/` by hand.
5. Trust the documentation more than your memory. Check the `rust-version` or the edition in `Cargo.toml` before you use a new API.
