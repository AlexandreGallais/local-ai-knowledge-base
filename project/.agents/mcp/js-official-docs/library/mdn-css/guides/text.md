# CSS text

The **CSS text** module defines how to perform text manipulation, like line breaking, justification and alignment, white space handling, and text transformation.

## Reference

### Properties

- `hanging-punctuation`
- `hyphenate-character`
- `hyphenate-limit-chars`
- `hyphens`
- `letter-spacing`
- `line-break`
- `overflow-wrap` (and the `word-wrap` alias)
- `tab-size`
- `text-align`
- `text-align-last`
- `text-fit`
- `text-indent`
- `text-justify`
- `text-autospace`
- `text-spacing-trim` (experimental)
- `text-transform`
- `text-wrap`
- `text-wrap-mode`
- `text-wrap-style`
- `white-space`
- `white-space-collapse`
- `word-break`
- `word-spacing`

The specification also defines the `hyphenate-limit-last`, `hyphenate-limit-zone`, `line-padding`, `text-align-all`, `text-group-align`, `text-spacing`, `word-space-transform`, `wrap-after` and `wrap-before` properties, which are not yet supported by any browser.
