# `:last-child` CSS pseudo-class

The **`:last-child`** CSS pseudo-class represents the last element among a group of sibling elements.

```css
p {
  font-weight: bold;
}

li:last-child {
  border: 2px solid orange;
}
```

<ul>

## Syntax

```css
:last-child {
  /* ... */
}
```

## Examples

### Basic <example-value>

#### HTML

```html
<div>
  <p>This text isn't selected.</p>
  <p>This text is selected!</p>
</div>

<div>
  <p>This text isn't selected.</p>
  <h2>This text isn't selected: it's not a `p`.</h2>
</div>
```

#### CSS

```css
p:last-child {
  color: lime;
  background-color: black;
  padding: 5px;
}
```

#### Result

### Styling a list

#### HTML

```html
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>
    Item 3
    <ul>
      <li>Item 3.1</li>
      <li>Item 3.2</li>
      <li>Item 3.3</li>
    </ul>
  </li>
</ul>
```

#### CSS

```css
ul li {
  color: blue;
}

ul li:last-child {
  border: 1px solid red;
  color: red;
}
```
