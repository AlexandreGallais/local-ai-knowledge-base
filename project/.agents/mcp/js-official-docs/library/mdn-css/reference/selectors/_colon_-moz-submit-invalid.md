# `:-moz-submit-invalid` CSS pseudo-class

The **`:-moz-submit-invalid`** CSS pseudo-class is a Mozilla extension that represents any submit `` on forms whose contents aren't valid based on their validation constraints.

By default, no style is applied. You can use this pseudo-class to customize the appearance of the submit button when there are invalid form fields.

## Syntax

```css
:-moz-submit-invalid {
  /* ... */
}
```

## Specifications

Not part of any standard.
