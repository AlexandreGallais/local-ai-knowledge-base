# `::-webkit-search-cancel-button` CSS pseudo-element

The **`::-webkit-search-cancel-button`** CSS pseudo-element represents a button (the "cancel button") at the edge of an `` of `type="search"` which clears away the current value of the `` element. This button and pseudo-element are non-standard, supported only in WebKit and Blink, hence the vendor prefix. The clear button is only shown on non-empty search `` elements.

## Syntax

```css
selector::-webkit-search-cancel-button {
  /* ... */
}
```

## Specifications

Not part of any standard.
