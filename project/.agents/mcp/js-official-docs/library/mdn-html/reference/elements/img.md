# `<img>` HTML image embed element

The **``** HTML element embeds an image into the document.

```html
<img
  class="fit-picture"
  src="/shared-assets/images/examples/grapefruit-slice.jpg"
  alt="Grapefruit slice atop a pile of other slices" />
```

```css
.fit-picture {
  width: 250px;
}
```
