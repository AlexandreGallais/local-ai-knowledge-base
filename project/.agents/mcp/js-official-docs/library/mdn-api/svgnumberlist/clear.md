# SVGNumberList: clear() method

The **`clear()`** method of the `SVGNumberList` interface clears all existing items from the list, with the result being an empty list.

## Syntax

```js
clear()
```

### Parameters

None.

### Return value

None (`undefined`).

### Exceptions

- `NoModificationAllowedError` `DOMException`
    Thrown if the `SVGNumberList` corresponds to a read-only attribute or when the object itself is read-only.
