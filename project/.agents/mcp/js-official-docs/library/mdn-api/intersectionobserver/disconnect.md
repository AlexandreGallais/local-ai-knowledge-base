# IntersectionObserver: disconnect() method

The **`disconnect()`** method of the `IntersectionObserver` interface stops the observer watching all of its target elements for visibility changes.

## Syntax

```js
disconnect()
```

### Parameters

None.

### Return value

None (`undefined`).
