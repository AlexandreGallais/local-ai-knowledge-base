# CSSSkew: CSSSkew() constructor

The **`CSSSkew()`** constructor creates a new `CSSSkew` object which represents the `skew()` value of the individual `transform` property in CSS.

## Syntax

```js
new CSSSkew(ax, ay)
```

### Parameters

- `ax`
    A value for the `ax` (x-axis) angle of the `CSSSkew` object to be constructed.
    This must be a `CSSNumericValue`.
- `ay`
    A value for the `ay` (y-axis) angle of the `CSSSkew` object to be constructed.
    This must be a `CSSNumericValue`.
