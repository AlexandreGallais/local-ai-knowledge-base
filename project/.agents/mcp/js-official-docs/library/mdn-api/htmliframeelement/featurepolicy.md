# HTMLIFrameElement: featurePolicy property

The **`featurePolicy`** read-only
property of the `HTMLIFrameElement` interface returns the
`FeaturePolicy` interface which provides a simple API for introspecting
the Permissions Policies applied to a specific frame.

## Value

A `FeaturePolicy` object
that can be used to inspect the Permissions Policy settings applied to the frame.
