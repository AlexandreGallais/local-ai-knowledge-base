# Navigator: appName property

The **`appName`** read-only property of the `Navigator` interface is always `"Netscape"`, in any browser. This property is kept only for compatibility purposes.

> **Note:**
> Do not rely on this property to return a real browser name. All browsers return `"Netscape"` as the value of this property.

## Value

The string `"Netscape"`.
