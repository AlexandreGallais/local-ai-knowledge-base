# Navigator: product property

The **`product`** read-only property of the `Navigator` interface is always `"Gecko"`, in any browser. This property is kept only for compatibility purposes.

> **Note:**
> Do not rely on this property to return a real product name. All browsers return `"Gecko"` as the value of this property.

## Value

The string `"Gecko"`.
