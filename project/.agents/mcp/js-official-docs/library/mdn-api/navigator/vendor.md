# Navigator: vendor property

The **`vendor`** read-only property of the `Navigator` interface is always either `"Google Inc."`, `"Apple Computer, Inc."`, or (in Firefox) the empty string.

## Value

Either `"Google Inc."`, `"Apple Computer, Inc."`, or (in Firefox) the empty string.
