# XRLayer

The **`XRLayer`** interface of the WebXR Device API is the base class for WebXR layer types. It inherits methods from `EventTarget`.

## Interfaces based on `XRLayer`

Below is a list of interfaces based on the `XRLayer` interface.

- `XRCompositionLayer`
- `XRWebGLLayer`

## Instance methods

_Inherits methods from its parent, `EventTarget`_.
