# Web Authentication API

The Web Authentication API (WebAuthn) is an extension of the Credential <example-value> API that enables strong authentication with public key <example-value>, enabling passwordless authentication and secure multi-factor authentication (MFA) without SMS texts.

On the web, passkeys are implemented using the Web Authentication API.
