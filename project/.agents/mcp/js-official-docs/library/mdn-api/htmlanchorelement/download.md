# HTMLAnchorElement: download property

The **`download`** property of the `HTMLAnchorElement` interface is a string indicating that the linked resource is intended to be downloaded rather than displayed in the browser. The value, if any, represents the proposed name of the file. It reflects the `download` attribute of the `` element.

See the HTML `` element reference for details about the attribute.

## Value

A string.
