# USBDevice: reset() method

The **`reset()`** method of the `USBDevice`
interface returns a `Promise` that resolves when the device is reset and all
app operations canceled and their promises rejected.

## Syntax

```js
reset()
```

### Parameters

None.

### Return value

A `Promise`.
