# Keyboard: unlock() method

The **`unlock()`** method of the
`Keyboard` interface unlocks all keys captured by the
`Keyboard.lock()` method and returns synchronously.

## Syntax

```js
unlock()
```

### Parameters

None.

### Return value

None (`undefined`).
