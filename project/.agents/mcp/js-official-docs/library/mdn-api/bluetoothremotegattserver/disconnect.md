# BluetoothRemoteGATTServer: disconnect() method

The **`BluetoothRemoteGATTServer.disconnect()`** method causes
the script execution environment to disconnect from `this.device`.

## Syntax

```js

```

### Parameters

None.

None (`undefined`).
