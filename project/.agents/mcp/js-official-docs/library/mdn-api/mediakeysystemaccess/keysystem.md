# MediaKeySystemAccess: keySystem property

The **`keySystem`** read-only property of the `MediaKeySystemAccess` interface returns a string identifying the key <example-value> being used.

This is the value that was passed to `Navigator.requestMediaKeySystemAccess()` when system access is requested.

## Value

A string.
