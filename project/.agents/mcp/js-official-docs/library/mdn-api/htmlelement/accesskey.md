# HTMLElement: accessKey property

The **`HTMLElement.accessKey`** property sets the keystroke which a user can press to jump to a given element.

> **Note:**
> The `HTMLElement.accessKey` property is seldom used because of its multiple conflicts with already present key <example-value> in browsers. To work around this, browsers implement accesskey <example-value> if the keys are pressed with other "qualifying" keys (such as `Alt` + accesskey).
