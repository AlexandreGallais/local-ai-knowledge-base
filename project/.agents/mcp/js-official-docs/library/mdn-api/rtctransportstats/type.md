# RTCTransportStats: type property

The **`type`** property of the `RTCTransportStats` dictionary is a string with the value `"transport"`.

Different statistics are obtained by iterating the `RTCStatsReport` object returned by a call to `RTCPeerConnection.getStats()`.
The type indicates the set of statistics available through the object in a particular iteration step.
A value of `"transport"` indicates that the statistics available in the current step are those defined in `RTCTransportStats`.

## Value

A string with the value `"transport"`.
