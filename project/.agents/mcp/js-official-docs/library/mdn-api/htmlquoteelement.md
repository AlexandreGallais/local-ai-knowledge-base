# HTMLQuoteElement

The **`HTMLQuoteElement`** interface provides special properties and methods (beyond the regular `HTMLElement` interface it also has available to it by inheritance) for manipulating quoting elements, like `` and `<q>`, but not the `` element.

## Instance properties

_Inherits properties from its parent, `HTMLElement`._

- `HTMLQuoteElement.cite`
    A string reflecting the `cite` HTML attribute, containing a URL for the source of the quotation.

## Instance methods

_No specific method; inherits methods from its parent, `HTMLElement`._
