# HTMLTextAreaElement: selectionEnd property

The **`selectionEnd`** property of the `HTMLTextAreaElement` interface specifies the end position of the current text selection in a `<textarea>` element.

For general information about this property, see `HTMLInputElement.selectionEnd`.

## Value

A non-negative number representing the zero-based index immediately after the last selected character, or the caret position if no text is selected.
