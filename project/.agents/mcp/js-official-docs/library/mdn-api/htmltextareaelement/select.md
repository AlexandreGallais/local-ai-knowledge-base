# HTMLTextAreaElement: select() method

The **`select()`** method of the `HTMLTextAreaElement` interface selects all the text in a `<textarea>` element.

For general information about this method, see `HTMLInputElement.select()`.

## Syntax

```js
select()
```

### Parameters

None.

### Return value

None (`undefined`).
