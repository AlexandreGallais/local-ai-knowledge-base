# HTMLTextAreaElement: selectionStart property

The **`selectionStart`** property of the `HTMLTextAreaElement` interface specifies the start position of the current text selection in a `<textarea>` element.

For general information about this property, see `HTMLInputElement.selectionStart`.

## Value

A non-negative number representing the zero-based index of the first selected character, or the caret position if no text is selected.
