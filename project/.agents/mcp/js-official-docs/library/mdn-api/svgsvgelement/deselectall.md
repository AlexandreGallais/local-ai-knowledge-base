# SVGSVGElement: deselectAll() method

The `deselectAll()` method of the `SVGSVGElement` interface unselects any selected objects, including any selections of text strings and type-in bars.

## Syntax

```js
deselectAll()
```

### Parameters

None.

### Return value

None.
