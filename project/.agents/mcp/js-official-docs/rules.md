# Official documentation of JavaScript and TypeScript

1. When your memory of an API is not sure, look it up with the `js-official-docs` server: `search_docs`, then `read_doc` on one section.
2. It holds MDN (JavaScript, HTML, CSS, Web APIs, SVG, HTTP, accessibility), Angular, TypeScript, RxJS, NgRx Signals, Node.js, npm, Vite, Vitest, Playwright, ESLint and its plugins, Stylelint.
3. Read one section at a time. Never read the folder `.agents/mcp/js-official-docs/library/` by hand.
4. Trust the documentation more than your memory. When the project uses a newer major version than the documentation, trust `package.json` and the installed packages.
