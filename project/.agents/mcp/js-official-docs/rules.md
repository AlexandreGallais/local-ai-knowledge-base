# Official documentation of JavaScript and TypeScript

1. When your memory of an API is not sure, look it up with the `js-official-docs` server: `search_docs`, then `read_doc` on one section.
2. It holds MDN (JavaScript, HTML, CSS, Web APIs, SVG, HTTP, accessibility), the ARIA Authoring Practices Guide, Angular (guides, API reference, CLI), TypeScript (handbook, tsconfig options), RxJS and NgRx Signals (guides and API reference), Node.js, npm, Vite, Vitest, Playwright, Storybook, Sass, Prettier, EditorConfig, ESLint and Stylelint with the plugins of the project.
3. Search an API by its exact name, as `inject`, `switchMap` or `withComputed`; a `tsconfig` option by its name, as `noUncheckedIndexedAccess`; a lint rule by its id.
4. To write an accessible component, read the pattern of the ARIA Authoring Practices Guide first (`tool: "aria-practices"`).
5. Read one section at a time. Never read the folder `.agents/mcp/js-official-docs/library/` by hand.
6. Trust the documentation more than your memory. When the project uses a newer major version than the documentation, trust `package.json` and the installed packages.
