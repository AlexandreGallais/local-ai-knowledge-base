# Knowledge base for a local AI

A knowledge base, rules, skills and tools that help a small local language model write
production code.

## Status

- Version 0.1 is archived in [`archive/v0.1/`](archive/v0.1/README.md), unchanged, with its
  history. It covers TypeScript, Angular, C#, containers and other topics.
- Version 0.2 is being planned. It covers JavaScript, TypeScript, Angular, HTML and CSS only.
