# French to English simulation vocabulary

Contents: 1. How to use · 2. Terms A to L · 3. Terms M to Z · Sources

## 1. How to use the simulation vocabulary

- Find the French term in the first column, lowercase. Use the English term in code, names and answers.
- "Reprise" names both the run after a freeze and the restore of a saved state: in English and in code, keep `Run` and `Restore` apart.
- Several French terms follow the usage of the team, not a published definition: check them against the internal glossary. [S1] [S2] [S3] [S4]
