- [Write a C# unit test that checks something](docs/dotnet-testing/unit-test-rules.md): The mistakes models make in tests, the rule against each, wrong and right C# examples, and the analyzers.
- [.NET integration tests](docs/dotnet-testing/integration-tests.md): Test an ASP.NET Core API, a database, the clock, HttpClient and SignalR without network, with WebApplicationFactory and FakeTimeProvider.
