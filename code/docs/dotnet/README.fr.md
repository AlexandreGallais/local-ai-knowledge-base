# C# et .NET à la version du projet

Ce qui a changé dans C#, .NET, ASP.NET Core et EF Core de la version 6 à la 11, pour que l'IA
écrive du code à la version du projet, lue dans le `TargetFramework` du fichier `.csproj`.

| Fichier | Ce qu'il contient |
| --- | --- |
| `csharp-changes.md` | La version de C# selon le framework cible, et la syntaxe permise de C# 10 à C# 15. |
| `dotnet-changes.md` | Les API intégrées qui remplacent des paquets tiers, les changements cassants courants, les applications à fichier unique, l'AOT natif. |
| `aspnetcore-changes.md` | ASP.NET Core : hébergement, API minimales, résultats typés, OpenAPI intégré, validation. |
| `efcore-changes.md` | EF Core : nouveautés et changements cassants de chaque version, avec leur correction. |
| `paid-packages.md` | Les bibliothèques devenues payantes (AutoMapper, MediatR, MassTransit, FluentAssertions, Polly) et leurs remplacements libres. |
