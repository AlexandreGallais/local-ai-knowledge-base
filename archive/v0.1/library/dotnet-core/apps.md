# Build apps with .NET

.NET has support for building many kinds of apps, including client, cloud, and gaming.

## Cloud apps

* Aspire
* Serverless functions
* Web and microservices

## Client apps

* Mobile
* Games
* Desktop apps

## Other app types

* Console apps
* Internet of Things (IoT)
* Machine learning
* Windows services
