# Built-in metrics in .NET

This is a reference for metrics built-in for .NET, produced using the
`System.Diagnostics.Metrics` API.

- .NET runtime metrics
- .NET extensions metrics
- System.Net metrics
- ASP.NET Core metrics
- Entity Framework Core Metrics

## Older metric APIs

For built-in metrics produced by alternative metric APIs,
see the EventCounters reference and Windows Performance Counter reference.
