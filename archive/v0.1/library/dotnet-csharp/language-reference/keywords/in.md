# `in` (C# reference)

Use the `in` keyword in the following contexts:

- Generic type parameters in generic interfaces and delegates.
- As a parameter modifier, which you use to pass an argument to a method by reference rather than by value.
- foreach statements.
- from clauses in LINQ query expressions.
- join clauses in LINQ query expressions.
