# Compiler Error CS0587

Internal Compiler Error: stage 'stage'

 Try to determine if the compiler is failing due to its inability to parse unexpected syntax. If this is not the case, see Visual Studio feedback options.

> **Note:**
> This compiler error is no longer used in Roslyn.
