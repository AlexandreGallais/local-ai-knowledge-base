# origin

The **`origin`** attribute specifies the origin of motion for an animation. It has no effect in SVG.

You can use this attribute with the following SVG elements:

- `<animateMotion>`

## Context notes

       | Value
       | `default`

       | Default value
       | `default`

       | Animatable
       | No
