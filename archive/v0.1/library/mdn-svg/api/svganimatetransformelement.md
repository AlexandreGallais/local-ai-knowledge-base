# SVGAnimateTransformElement

The `SVGAnimateTransformElement` interface corresponds to the `<animateTransform>` element.

## Instance properties

_This interface has no properties but inherits properties from its parent, `SVGAnimationElement`._

## Instance methods

_This interface has no methods but inherits methods from its parent, `SVGAnimationElement`._
