# Rust for C# readers

Contents: 1. Ownership · 2. Types and traits · 3. Errors · 4. Collections and modules · Sources

Kind: "same meaning" reads as in C#; "false friend" looks like C# but means something else; "no equivalent" has no C# counterpart. Ownership replaces the garbage collector; `Result` replaces exceptions. The 2024 edition came with Rust 1.85.0. [S5]

## 1. Ownership and lifetimes (Rust)

| You read | Meaning | C# equivalent | Kind |
| --- | --- | --- | --- |
| `let s2 = s1;` | Move: `s1` can no longer be used, a compile error otherwise [S2] | Both variables stay valid in C# | false friend |
| `f(s)` | Passing a value moves it too, except `Copy` types (integers, `bool`, floats, `char`) [S2] | — | false friend |
| `s1.clone()` | Explicit deep copy [S2] | `Clone()` | same meaning |
| End of block `}` | The value is dropped when its owner leaves scope [S2] | `IDisposable` and `using`, but automatic [S1] | no equivalent |
| `fn f<'a>(x: &'a str) -> &'a str` | Lifetime: links reference durations for the compiler; changes nothing at run time [S3] | None | no equivalent |
| `&'static str` | A reference valid for the whole program, a literal for example [S3] | — | no equivalent |

## 2. Types and traits (Rust)

| You read | Meaning | C# equivalent | Kind |
| --- | --- | --- | --- |
| `struct` and `impl` | Data, then methods in a separate block; no inheritance [S1] | `class` | same meaning |
| `trait` and `impl Trait for Type` | Interface, with possible default methods [S1] | `interface` [S1] | same meaning |
| `#[derive(Debug, Clone, PartialEq)]` | Code generated by a macro; value equality comes from `PartialEq` [S1] | Members synthesized for a `record` | no equivalent |
| `enum E { A(i32), B }` and `match` | Each variant can carry data [S1] | No direct equivalent; TypeScript discriminated union | false friend |
| `Option<T>`, `Some(v)`, `None` | No `null`; `map` and `and_then` for `?.`, `unwrap_or` for `??`, `unwrap` for `!` [S1] | `T?` | same meaning |

## 3. Errors (Rust)

| You read | Meaning | C# equivalent | Kind |
| --- | --- | --- | --- |
| `Result<T, E>`, `Ok(v)`, `Err(e)` | No exceptions: the error is in the signature [S1] [S4] | `try`/`catch` | no equivalent |
| `expr?` | On `Err`, returns at once from the function, after converting the error with `From` [S4] | Rethrow; nothing to do with `?.` | false friend |
| `.unwrap()`, `.expect("…")`, `panic!` | Stop on error; `panic!` signals a bug, not an expected error [S4] [S1] | Unhandled exception | same meaning |

## 4. Collections and modules (Rust)

| You read | Meaning | C# equivalent | Kind |
| --- | --- | --- | --- |
| `.iter().filter(…).map(…).collect()` | Lazy iterators; iterating a `Vec` by value consumes it [S1] | LINQ `Where`, `Select`, `ToList` [S1] | same meaning |
| `mod`, `pub`, `pub(crate)` | Module; private by default; `pub(crate)` is `internal` [S1] | `namespace`, `internal` | same meaning |
| `#[cfg(test)] mod tests`, `#[test]` | Unit tests in the same file [S1] | A separate test project | no equivalent |

Macros, `unsafe` and `async` are in `docs/reading-code/rust-macros-unsafe-async.md`. The full borrowing rules were not read in an open page for this base.
