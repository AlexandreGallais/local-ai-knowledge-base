# reading-code index

One line per document. Open only the documents your task needs.

- [C for C# readers](docs/reading-code/c-for-csharp-readers.md): Pointers, arrays, manual memory, headers, macros and undefined behavior in C, with C# equivalents. C23.
- [C embedded idioms](docs/reading-code/c-embedded-idioms.md): Bit-fields, volatile, fixed-point Q format, memory-mapped registers and interrupt handlers in embedded C. C23.
- [C++ for C# readers](docs/reading-code/cpp-for-csharp-readers.md): RAII, smart pointers, move, templates and overloads in C++, each marked same meaning, false friend or no equivalent.
- [C++ version markers](docs/reading-code/cpp-version-markers.md): Syntax markers that date a C++ excerpt, from C++11 to C++23, to find the oldest standard it needs.
- [Java for C# readers](docs/reading-code/java-for-csharp-readers.md): Erased generics, checked exceptions, records, sealed types, streams and annotations in Java, with C# equivalents. Java 25.
- [Java framework idioms](docs/reading-code/java-framework-idioms.md): What Spring and Lombok annotations do without showing it in the code, and the C# landmark of each.
- [Rust for C# readers](docs/reading-code/rust-for-csharp-readers.md): Ownership, borrowing, lifetimes, traits, Option, Result and the question mark in Rust, with C# equivalents. Edition 2024.
- [Rust macros, unsafe and async](docs/reading-code/rust-macros-unsafe-async.md): Macros, unsafe blocks, foreign functions, async futures and memory-mapped registers in embedded Rust, with C# landmarks.
- [Reading CMakeLists.txt and Makefile](docs/reading-code/build-cmake-make.md): What CMakeLists.txt and a Makefile say about a C or C++ project, with targets, dependencies, macros and standard.
- [Reading pom.xml, build.gradle and Cargo.toml](docs/reading-code/build-maven-gradle-cargo.md): What pom.xml, build.gradle and Cargo.toml say about a Java or Rust project, with versions, dependencies and features.
