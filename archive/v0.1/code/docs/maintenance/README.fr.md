# Entretien de la base

Les procédures pour tenir la base à jour.

| Fichier | Ce qu'il contient |
| --- | --- |
| `update-a-tool.md` | La procédure pas à pas pour mettre à jour les documents d'un outil quand il sort une nouvelle version majeure, Angular d'abord, jouée sur le passage d'Angular 21 à 22. |

Pour savoir quels documents sont en retard sur un projet : `node scripts/check-versions.ts <projet>`.
